## Резиновая типографика (боевой пакет, в прототипе спит)
```css

/* ПРАВИЛО (в бой): в боевом приложении типографика обязана быть резиновой —
   этот блок переносится в боевой CSS как есть (media="not all" снять),
   а px-размеры текста переводятся в rem по таблице из комментария выше. */
/* Корневая шкала: на узком телефоне текст чуть мельче, на широком чуть
   крупнее, между ними плавно тянется от ширины экрана. 4.1vw подобран так,
   что на 375px даёт ~15.4px, на 430px ~17.6px, упоры не дают крайностей. */
html{ font-size:clamp(15px, 4.1vw, 18px); }

/* Планшет и десктоп-веб: рост останавливается, интерфейс не раздувается. */
@media (min-width:768px){ html{ font-size:17px; } }

/* Уважение к настройкам доступности: если человек в системе включил
   крупный текст, браузерный масштаб перемножается с rem автоматически —
   ничего дополнительно делать не нужно, именно поэтому rem, а не px. */

/* Страховки от разъезда на самом узком экране (375px и уже): длинные
   ивритские/русские слова переносятся, числа не рвут строки. */
@media (max-width:379px){
  body{ overflow-wrap:anywhere; }
  .num{ letter-spacing:-.01em; }
}

```
