### Карта состояний экранов (поведение)
У каждого экрана четыре состояния. Пустота учит и даёт первый шаг; загрузка — «кости»
по форме контента, макет не прыгает; ошибка — по-человечески, без кодов, всегда с «Повторить»;
успех — обычная жизнь экрана.

**Главная**
- Пусто: дом только создан: приветствие, карточка «Расскажите о квартире» и один большой шаг — пригласить соседей
- Загрузка: кости: строка приветствия, две карточки-плашки; без прыжков макета
- Ошибка: «Не получилось обновить дом» + Повторить; последняя удачная картина остаётся на экране
- Успех: приветствие, платёж месяца, объявления, голосование — по схеме и поведению студии

**Финансы**
- Пусто: счёт дома пуст: «Здесь появится касса дома» + шаг ваада — назначить взнос
- Загрузка: кости: полоса остатка и три строки движений
- Ошибка: «Касса не отвечает» + Повторить; цифры не выдумываем — показываем прочерк
- Успех: остаток, движения, месяцы; долги подсвечены спокойно, без крика

**Оплата**
- Пусто: взнос не назначен: «Ваад ещё не назначил взнос» — жильцу делать нечего, кнопки нет
- Загрузка: кость на месте суммы; кнопка оплаты выключена, пока сумма не пришла
- Ошибка: «Оплата не прошла, деньги не списаны» + Повторить; двойное нажатие не создаёт второй платёж
- Успех: сумма, за какие месяцы, одна кнопка оплаты; после успеха — квитанция

**Голосование**
- Пусто: «Пока нет открытых голосований» + вааду кнопка создать первое
- Загрузка: кости: вопрос и две плашки-ответа
- Ошибка: «Голос не долетел» + Повторить; свой выбор виден локально, не теряется
- Успех: вопрос, варианты, мой голос, срез результатов — пока открыто

**Заявки**
- Пусто: «Заявок нет — в доме порядок» + кнопка «Сообщить о поломке»
- Загрузка: кости: три строки заявок
- Ошибка: «Список не загрузился» + Повторить
- Успех: список по статусам: новая — в работе — готово; своя заявка сверху

**Чат дома**
- Пусто: «Здесь соседи договариваются» + поле сразу активно — первый пишет без порога
- Загрузка: кости-пузыри двух сторон
- Ошибка: «Сообщение не ушло» — пометка у пузыря + Повторить именно его; текст не пропадает
- Успех: лента, новые снизу, непрочитанное считается на колокольчике по правилам пушей

**Объявления**
- Пусто: «Объявлений пока нет»; вааду — кнопка написать первое, жильцу — тишина без кнопки
- Загрузка: кости: две карточки объявлений
- Ошибка: «Доска не загрузилась» + Повторить
- Успех: свежее сверху; важное от ваада помечено; прочитанность не требуем

**Специалисты**
- Пусто: «В вашем районе пока нет специалистов» + пригласить своего мастера в один тап
- Загрузка: кости: три карточки специалистов
- Ошибка: «Каталог не отвечает» + Повторить
- Успех: карточки: имя, дело, оценка, связь через приложение; контакты по гейту

### Правила показа блоков (словами)
Каждый живой блок знает три позы: во весь рост, ужат в строку, скрыт.

- **Здоровье дома** — скрывается целиком, если у дома нет ни одного показателя (новый дом, данных нет) _(видит: жилец, ваад)_
- **Долг по оплате** — сжимается в одну строку-плашку, если долга нет — не съедает место _(видит: жилец, ваад)_
- **Открытое голосование** — показывается только пока идёт хоть одно; исчезает само по завершении _(видит: жилец, ваад)_
- **Промо-слот** — скрыт, если админ выключил все промо и нет активного специалиста-плитки _(видит: жилец)_
- **Лента событий** — показывает последние записи; при пустой ленте — приветственная заглушка, не пустое место _(видит: жилец, ваад)_
- **Карточка «ждём дом»** — меняется на карточку одобрения/анкеты по мере продвижения; никогда не дублируются одновременно _(видит: пользователь без дома)_

### Зоны экрана (кто где живёт)
Сверху вниз. Порядок зон задаёт слой «Схема»; в зоне «Герой» стоит одно,
по приоритету: долг → открытое голосование → сводка дома.

1. **Шапка** — приветствие, адрес дома, колокольчик, кошелёк — всегда наверху
2. **Герой** — главное сейчас, одно: долг, открытое голосование или сводка дома
3. **Действия** — плитки разделов — Мой дом, Финансы, Документы, Голосование
4. **Лента** — жизнь дома: объявления, события — свежее выше
5. **Навигация** — низ экрана, по выбранной раскладке: меню-экран, островок или плитки

### Скелет главных экранов (собран владельцем, Пакет 8)
**Главная жильца** — ручной скелет не задан: порядок блоков решает выбранная схема (слой 7).

**Главная председателя** — ручной скелет не задан: порядок блоков решает выбранная схема (слой 7).

Правило для инженера: ручной скелет владельца сильнее автоматической схемы;
блоки — это реестр IA в resHomeHTML()/vaadHomeHTML(), id блоков совпадают.

### Ночной вид выводится расчётом, а не рисуется заново

Тёмный режим — не второй облик, а отражение этого же. Правило:

- фон: `color-mix(in srgb, АКЦЕНТ 8%, #10111A 92%)`
- карточка: `color-mix(in srgb, АКЦЕНТ 10%, #191B24 90%)`
- линии: `color-mix(in srgb, АКЦЕНТ 16%, #2C2F3A 84%)`
- чернила: `#ECEDF2`
- **акцент: `color-mix(in srgb, АКЦЕНТ 55%, #fff 45%)`** — он должен
  подняться до яркости, различимой на тёмном, иначе кнопка сливается с фоном;
- текст на кнопке в ночи — тёмный (`#10121A`): на светлом акценте белый не читается.

### Размеры текста — шесть ступеней, и больше никаких

`--t-xs:10px` подписи · `--t-s:11.5px` второстепенное · `--t-m:12.5px` основной
текст · `--t-l:14px` подзаголовки · `--t-xl:17px` заголовки · `--t-num:22px` числа.

Толщина — три ступени: 700 главное · 600 подзаголовок · 400 обычное.
