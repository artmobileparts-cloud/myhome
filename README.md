# «Мой Дом» — боевое приложение из прототипа

В репозитории две разные вещи, и путать их нельзя:

- **прототип** (`src/prototype.html`) — сцена показа: пульт, четыре телефона
  рядом, админка, магазин приложений, имитаторы оплаты и пушей, ревизор.
  Это **источник правды**, он не правится под сборку и лежит как есть.
- **боевое приложение** — один экран одного человека. В репозитории его нет
  готовым файлом: оно **вынимается из прототипа скриптом** при каждой сборке.

## Почему выемкой, а не копией

Прототип живой и продолжает меняться. Копия, вырезанная руками, устареет к
следующей сборке и начнёт тихо врать. `tools/extract-prod.mjs` переносит любую
правку прототипа в приложение одной командой.

Границу провёл не сборщик, а сам прототип — закон разделения демо/бой
(06.08.2026): лес несёт метку «ДЕМО» и `data-scope="demo"`, админка —
`data-scope="admin"`, список лесов лежит в `SCAFFOLD_FNS`. Выемка эти метки
просто исполняет.

Каждый шаг выемки обязан совпасть **ровно один раз**. Прототип изменился так,
что кусок не найден — сборка останавливается и называет место, вместо того
чтобы молча собрать сломанное приложение. Удаление каждого леса дополнительно
проверяется на разбор кода и откатывается, если ломает.

## Что вынуто из боевой сборки

| Убрано | Почему |
|---|---|
| пульт сцены, панель дизайна, панель смотра | инструменты стройки |
| три соседних телефона и подписи над ними | в бою телефон один — настоящий |
| админка | отдельное приложение, не для телефона жильца |
| магазин приложений, рабочий стол, заставка | декорация вокруг приложения |
| корпус трубки, вырез камеры, статусбар, навигация | телефон настоящий |
| имитатор эквайринга и пушей | в бою — настоящий провайдер |
| ревизор в цикле перерисовки | правила сторожит сервер, не экран жильца |
| 37 демо-функций из `SCAFFOLD_FNS` | те самые «леса» |

Приложение стартует там же, где в жизни после установки: экран входа и
регистрации, без подсунутой сессии.

## Что где лежит

| Путь | Что это |
|---|---|
| `src/prototype.html` | прототип, источник правды, не правится |
| `src/prod.css` | боевая раскладка: приложение во весь экран |
| `www/app-shell.js` | оболочка: кнопка «Назад», внешние ссылки |
| `tools/extract-prod.mjs` | выемка боевого приложения |
| `tools/fetch-fonts.mjs` | вшивает шрифты внутрь приложения |
| `tools/make-assets.py` | значок приложения |
| `tools/check-xml.py` | проверка XML-ресурсов до сборки |
| `docs/` | комплект документации, начинать с `00-ЧИТАЙ-МЕНЯ.md` |
| `docs/рабочие-документы.html` | интерактивный сборник рабочих документов |
| `android/` | нативный проект (Capacitor) |

`www/index.html` и `www/prod.css` — **собираемые**, в репозитории их нет.

## Как получить APK

Сборка идёт в GitHub Actions — там уже установлен Android SDK.

1. Actions → **Android APK** → нужный запуск.
2. Внизу страницы, раздел **Artifacts** → `myhome-apk`.
3. Внутри `app-debug.apk`. Скинуть на телефон и открыть, разрешив установку
   из этого источника.

## Сборка на своей машине

Нужны Node 22, JDK 21 и Android SDK.

```bash
npm ci
npm run extract          # боевое приложение из прототипа
npm run fonts            # шрифты внутрь приложения (нужна сеть)
npm run apk:debug        # android/app/build/outputs/apk/debug/app-debug.apk
```

Посмотреть боевое приложение без Android: `npm run extract`, затем открыть
`www/index.html` в браузере.

## Релиз для магазина

Отладочный APK для магазина не годится — нужен свой ключ подписи.

```bash
keytool -genkeypair -v -keystore myhome.jks -keyalg RSA -keysize 2048 \
        -validity 10000 -alias myhome
```

Ключ **в репозиторий не кладётся**: тот, у кого он есть, выпускает обновления
приложения от вашего имени. Он живёт в секретах репозитория:

| Секрет | Значение |
|---|---|
| `MYHOME_KEYSTORE_BASE64` | `base64 -w0 myhome.jks` |
| `MYHOME_KEYSTORE_PASSWORD` | пароль хранилища |
| `MYHOME_KEY_ALIAS` | `myhome` |
| `MYHOME_KEY_PASSWORD` | пароль ключа |

Дальше: Actions → **Android APK** → Run workflow → галочка «Собрать релизный
APK». Номер сборки берётся из номера запуска, имя версии — из `package.json`.

## Чего ещё нет — честно

- **Сервера нет.** Приложение работает на памяти браузера. Настоящие вход по
  SMS, оплата, база и пуши — техника из `docs/06-ТОЧКИ-ДЕМО-В-БОЙ.md`.
- **Мир пустой.** Генератор демо-мира вынут вместе с лесами, а сервера ещё
  нет — данным взяться неоткуда. Видно устройство приложения, не жизнь в нём.
- **Код админки ещё лежит внутри** мёртвым грузом: она больше не рисуется и
  недостижима, но её функции пока не вынуты. Уйдут, когда админка станет
  отдельным приложением.
