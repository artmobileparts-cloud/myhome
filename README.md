# «Мой Дом» — Android-приложение

APK собирается **из прототипа**. Прототип (`src/prototype.html`) — источник
правды, он не правится под сборку.

## Главное: приложение делает сам прототип

С версии 24.08-530 прототип умеет превращаться в приложение — режим
`html.real`. На настоящем телефоне он сам:

- гасит пульт сцены, соседние телефоны и админку;
- убирает нарисованный корпус трубки, вырез камеры, статусбар и полосу
  Android-кнопок — у настоящего телефона всё это своё;
- ставит экран во весь размер устройства;
- считает верх и низ от настоящих системных отступов `env(safe-area-inset-*)`;
- прячет нижнюю панель на время набора;
- красит статус-зону цветом экрана.

Поэтому сборка короткая: `tools/build-app.mjs` добавляет ровно две вещи,
которых прототипу не хватает внутри обёртки.

1. **Режим настоящего телефона включается точно.** Прототип определяет его по
   сенсорному узкому экрану — на телефоне верно, на планшете мимо. Внутри
   обёртки сомнений нет.
2. **Приложение открывается приложением.** По умолчанию телефон сцены стоит
   «до установки» и показывает нарисованную страницу Google Play с кнопкой
   «Установить». В APK человек уже установил — открываем сразу на первом
   экране приложения: вход и регистрация.

Каждая правка обязана совпасть ровно один раз. Прототип изменился так, что
место не найдено — сборка останавливается и называет его, вместо того чтобы
молча собрать сломанное приложение.

## Требования прототипа к обёртке — выполнены

Прототип написал их сам, в блоке `html.real` своего CSS:

| Требование | Как выполнено |
|---|---|
| прозрачный статус-бар поверх WebView, тёмные значки по теме | Capacitor 8 даёт edge-to-edge сам; тон значков считает `www/app-shell.js` по яркости `--bg` — облик меняется примерочной и ночным режимом, значки идут за ним |
| настоящие `env(safe-area-inset-*)` в WebView | плагин SystemBars Capacitor 8, `insetsHandling: css` (по умолчанию) + `viewport-fit=cover` в прототипе |
| `adjustResize` | `android:windowSoftInputMode="adjustResize"` в манифесте |

## Проверочная дверь — ваша, не моя

В прототипе живёт **режим дыма**: пять тапов по строке сборки внизу первого
экрана → код → вход за роль (жилец, председатель, специалист, маклер,
админ-панель). Рубильник `ДЫМ.вкл`, срок годности `ДЫМ.до`. Это работа
владельца, сборка её не трогает и не добавляет своей.

Там же **примерочная обликов** (`FIT_ROOM`) — профиль → примерочная, выбор
палитры прямо в APK.

## Что где лежит

| Путь | Что это |
|---|---|
| `src/prototype.html` | прототип, источник правды, не правится |
| `tools/build-app.mjs` | сборка приложения из прототипа |
| `www/app-shell.js` | кнопка «Назад», внешние ссылки, тон значков статус-бара |
| `tools/fetch-fonts.mjs` | вшивает шрифты внутрь приложения |
| `tools/make-assets.py` | значок приложения |
| `tools/check-xml.py` | проверка XML-ресурсов до сборки |
| `tools/extract-prod.mjs` | тяжёлая выемка боевого кода — **не используется** |
| `docs/` | комплект документации, начинать с `00-ЧИТАЙ-МЕНЯ.md` |
| `android/` | нативный проект (Capacitor) |

`www/index.html` — собираемый, в репозитории его нет.

### Про `extract-prod.mjs`

Он вырезает демо-леса по меткам прототипа и оставляет только боевой код. Для
этого прототипа он стал вредным: дверь дыма берёт живых людей из построенного
мира, а мир строит `makeEnv`, помеченный как лес. Вырезав лес, мы обезоружили
бы дверь. Скрипт оставлен и пригодится, когда боевой код станет отдельным
продуктом. Запуск: `npm run strip`.

## Как получить APK

Actions → **Android APK** → нужный запуск → внизу **Artifacts** →
`myhome-apk` → внутри `app-debug.apk`.

## Сборка на своей машине

Нужны Node 22, JDK 21 и Android SDK.

```bash
npm ci
npm run app        # приложение из прототипа
npm run fonts      # шрифты внутрь приложения (нужна сеть)
npm run apk:debug  # android/app/build/outputs/apk/debug/app-debug.apk
```

Посмотреть на столе: открыть `www/index.html` с `?device=1` — прототип
включит режим настоящего телефона руками.

## Релиз для магазина

Отладочный APK для магазина не годится — нужен свой ключ подписи.

```bash
keytool -genkeypair -v -keystore myhome.jks -keyalg RSA -keysize 2048 \
        -validity 10000 -alias myhome
```

Ключ **в репозиторий не кладётся**: тот, у кого он есть, выпускает обновления
приложения от вашего имени. Он живёт в секретах репозитория:

| Секрет | Значение |
|---|---|
| `MYHOME_KEYSTORE_BASE64` | `base64 -w0 myhome.jks` |
| `MYHOME_KEYSTORE_PASSWORD` | пароль хранилища |
| `MYHOME_KEY_ALIAS` | `myhome` |
| `MYHOME_KEY_PASSWORD` | пароль ключа |

Дальше: Actions → **Android APK** → Run workflow → галочка «Собрать релизный
APK». Номер сборки — из номера запуска, имя версии — из `package.json`.

Перед боевым релизом выключить в прототипе `ДЫМ.вкл` и `FIT_ROOM`.

## Чего ещё нет

- **Сервера нет.** Приложение живёт на памяти телефона: настоящие вход по SMS,
  оплата, база и пуши — техника из `docs/06-ТОЧКИ-ДЕМО-В-БОЙ.md` и
  `docs/07-СЕРВЕРНЫЕ-ПРОВЕРКИ.md`.
- **Мир демонстрационный.** Прототип строит его сам при запуске: два дома,
  труппа. Это показ устройства приложения, а не рабочие данные.
