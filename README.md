# «Мой Дом» — Android-приложение из прототипа

Прототип `прототип.html` завёрнут в настоящее Android-приложение (Capacitor).
Веб-часть внутри приложения — тот же самый прототип, файл в файл; всё, что
добавлено сверху, лежит отдельно и помечено.

## Что где лежит

| Путь | Что это |
|---|---|
| `www/index.html` | прототип как есть — **источник правды** |
| `www/app-shell.js` | оболочка приложения: кнопка «Назад», внешние ссылки |
| `docs/` | комплект документации из архива, начинать с `00-ЧИТАЙ-МЕНЯ.md` |
| `android/` | нативный проект, создан `npx cap add android` |
| `tools/make-assets.py` | генератор значка приложения |
| `tools/fetch-fonts.mjs` | вшивает шрифты внутрь приложения перед сборкой |

Прототип **не переписан под приложение**: чтобы обновить его, достаточно
положить новый файл в `www/index.html` и вернуть на место последнюю строку
с подключением `app-shell.js` — она стоит перед `</body>`.

## Как получить APK

Сборка идёт в GitHub Actions — там уже установлен Android SDK.

1. Actions → **Android APK** → нужный запуск.
2. Внизу страницы, раздел **Artifacts** → `myhome-apk`.
3. Внутри `app-debug.apk`. Файл ставится на телефон напрямую: скинуть на
   устройство и открыть, разрешив установку из этого источника.

Сборка запускается сама на каждый push и вручную кнопкой **Run workflow**.

## Сборка на своей машине

Нужны Node 22, JDK 21 и Android SDK (Android Studio ставит всё сразу).

```bash
npm ci
node tools/fetch-fonts.mjs   # шрифты внутрь приложения, можно пропустить
npm run apk:debug            # android/app/build/outputs/apk/debug/app-debug.apk
```

## Релиз для магазина

Отладочный APK для магазина не годится — нужен свой ключ подписи.

```bash
keytool -genkeypair -v -keystore myhome.jks -keyalg RSA -keysize 2048 \
        -validity 10000 -alias myhome
```

Ключ **в репозиторий не кладётся**: тот, у кого он есть, выпускает обновления
приложения от вашего имени. Он живёт в секретах репозитория:

| Секрет | Значение |
|---|---|
| `MYHOME_KEYSTORE_BASE64` | `base64 -w0 myhome.jks` |
| `MYHOME_KEYSTORE_PASSWORD` | пароль хранилища |
| `MYHOME_KEY_ALIAS` | `myhome` |
| `MYHOME_KEY_PASSWORD` | пароль ключа |

Дальше: Actions → **Android APK** → Run workflow → галочка «Собрать релизный
APK». Номер сборки берётся из номера запуска, имя версии — из `package.json`.

## Чего в приложении пока нет

Оболочка не выдумывает того, чего нет в прототипе. Настоящие вход по SMS,
оплата, сервер и пуш-уведомления — это техника из `docs/06-ТОЧКИ-ДЕМО-В-БОЙ.md`,
она достраивается отдельно. Приложение сейчас показывает прототип целиком,
включая демо-слой и админ-панель.

Отдельно стоит знать: прототип — это **сцена с несколькими телефонами сразу**
(жилец, ваад, админка, маклер), он рисовался под широкий экран. На телефоне он
работает, но задуман был для показа, а не для одного жильца. Боевое приложение
для одного человека — это следующий шаг, а не эта обёртка.
